# Hi, I'm Mateo 👋

## Presentation

Hey! My name is Mateo and I’m a full-stack developer from Bahía Blanca, Argentina. I’m passionate about building software that solves real problems. I’m patient, sociable and collaborative, and I’m obsessive about details. I pay close attention to detail, both in the code and in the user experience.

## Skills

I’m interested in backend development, and for that I use C# and .NET. For the frontend, I use React with TypeScript. I can build scalable web applications with dynamic interfaces for the end user. I’m good at designing clean architectures, and I’m capable of working on a whole application, from the database to the user interface.

## Current work and education

I’m currently working as an independent developer, and I’m studying for a technical degree in programming at UTN in Bahía Blanca. I’m working on mediTool, a web application that helps health professionals manage their appointments and their patients. It’s almost ready for a real user to start using it.

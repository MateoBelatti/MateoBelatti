## 🚀 Proyectos Destacados

### 🌟 mediTool — Sistema Integral de Gestión Clínica y Turnos Recurrentes
> React · Vite · TypeScript · C# · ASP.NET Core · Entity Framework Core · PostgreSQL

Plataforma inteligente diseñada para la administración de clínicas de salud, optimizando la asignación de turnos médicos y el seguimiento de asistencias de pacientes y profesionales.

- **Motor de Agendamiento Inteligente:** Implementación de un motor de reglas en C# para turnos fijos (`TurnoFijo`) que genera automáticamente las instancias de citas individuales (`Turno`) en el calendario y propaga de forma inteligente modificaciones y cancelaciones hacia eventos futuros.
- **Arquitectura Limpia Multicapa:** Separación estricta de responsabilidades estructurada en `Api` (controladores, seguridad y mapeo de datos), `Service` (encapsulamiento de la lógica de negocio), `Repository` (patrón de acceso a datos desacoplado) y `Biblioteca` (definición de entidades del dominio y contexto de base de datos).
- **Persistencia de Datos:** Configuración e integración de **PostgreSQL** mediante **EF Core**, automatizando las migraciones de base de datos al iniciar la aplicación.
- **Seguridad y Control:** Autenticación y autorización basada en tokens **JWT (JSON Web Tokens)** con políticas CORS configuradas para un entorno de frontend SPA y middleware global para captura y estandarización de errores.

⚙️ [Backend](https://github.com/MateoBelatti/mediTool-backend) · 🖥️ [Frontend](https://github.com/MateoBelatti/mediTool-frontend)

### 🕯️ Canela Artesanías — E-commerce de productos artesanales
> React · Vite · TypeScript · C# · ASP.NET Core · EF Core · SQL Server

Plataforma de comercio electrónico con catálogo interactivo, carrito de compras en tiempo real y panel de administración avanzado protegido por roles.

- **Backend:** Arquitectura sólida en capas con patrón Repository sobre EF Core, control centralizado de excepciones y autenticación híbrida mediante JWT y Google OAuth.
- **Frontend:** Estructura modular orientada a features, persistencia y flujo de carrito administrado mediante Context API, rutas seguras protegidas por rol y formularios dinámicos validados de forma estricta.

🌐 [Ver demo](https://canelaartesanias.vercel.app/) · ⚙️ [Backend](https://github.com/MateoBelatti/AppShowroom-Backend) · 🖥️ [Frontend](https://github.com/MateoBelatti/AppShowroom-Frontend)

### 🔍 Ingened — Gestión de informes de inspección técnica
> React · Vite · TypeScript · C# · ASP.NET Core · EF Core · SQL Server

Herramienta interna para empresas de inspección técnica no destructiva, diseñada para crear, estructurar y exportar informes técnicos homologados.

- **Backend:** Capa de negocio especializada para el procesamiento y generación de PDFs en el servidor, integrada directamente con la API de Google Drive mediante Service Account para el almacenamiento automático y seguro de reportes generados.
- **Frontend:** Interfaz orientada a la carga de datos masiva y estructurada con formularios divididos por secciones con estado dinámico compartido y validaciones de esquema.

🌐 [Ver demo](https://ingenedpdf.vercelapp/) · ⚙️ [Backend](https://github.com/MateoBelatti/Ingened-Backend) · 🖥️ [Frontend](https://github.com/MateoBelatti/Ingened-Frontend)
